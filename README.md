CloudBudgetGuard
Stop getting surprised by cloud bills. Connect AWS with a read-only billing scope, see where spend goes, catch unexpected spikes, and get a weekly founder report.

▶️ Live demo — https://cloudbudgetguard.vercel.app
CloudBudgetGuard is a multi-tenant AWS cost-monitoring app fronted by a premium, real-time marketing experience.

Highlights
Real-time WebGL hero "Beam" — an original violet/indigo data-spine shader that flows downward and flares into the product dashboard (no video, no Three.js; direct WebGL).
Whole-product responsive preview — the live dashboard scaled into the hero on phones, natural full-size on tablet/desktop.
Anomaly detection vs a 7-day baseline, with email + opt-in WhatsApp alerts and a weekly founder report (cron + email + in-app).
Multi-tenant organization authorization with a separate platform-admin portal + audit trail.
Modular-monolith architecture with enforced boundaries, MongoDB migrations, and a hardened security baseline (nonce CSP, secret validation, rate-limited APIs).
Stack
Next.js (App Router) · React · TypeScript (strict) · Tailwind CSS v4 · WebGL · MongoDB · Vitest
